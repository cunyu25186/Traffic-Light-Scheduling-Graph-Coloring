# Traffic-Light-Scheduling-Graph-Coloring
#  多岔路口智能交通信号灯调度系统 (Traffic Light Scheduler)

本项目通过建立**数学模型**与**图着色算法 (Graph Coloring)**，解决了复杂五岔路口（13条通行路线）的车辆防碰撞与路权最优分配问题。

- 提取了符合现实交通规则的**“0号相位”**（不受红绿灯限制的外侧右转弯通道）。
- 采用了**贪心算法**对路线进行“极限拼车”调度，实现路口通行效率最大化。
- 提供 `C`, `C++`, `Python` 三个语言版本，核心逻辑统一，全部通过无碰撞测试。

 运行结果
算法稳定输出 1 个常绿相位 + 4 个互斥绿灯相位，彻底消除了路口中心交叉冲突。
